# Highline

[Play the latest build — v0.18.0](https://kingmadellc.github.io/Highline/?v=0.18.0)

A Unity surfing playtest set in Satellite Beach, Florida. Play in landscape on a phone or in a desktop browser. The WebGL assets total roughly 71 MB; later visits can reuse the browser cache. This repository contains the playable WebGL release.

Version 0.18 makes short thumb corrections settle faster, adds clearer board/rider/rail-spray feedback, guides a chosen high line onto the lip, and carries landing momentum into the next move. Push farther through the crest to launch or draw down to return. Learn mode helps more released rotations settle; precise landings still earn more speed and points, while Standard remains stricter. The still start scene and brief title signature are retained.


Pull toward yourself and hold to paddle; release in the timing window to stand. Draw low for speed, approach the lip to ride it, or drive through it to launch. Move sideways in the air to rotate and release before landing. Keep riding to bank the air. Practice a line, catch a wave, or try a three-wave filming set.

The canonical Play link opens the latest release. Each version uses its own asset directory to avoid stale mixtures of game files. Reload an already-open game tab to pick up a new release. `build-info.json` records the version and exact file hashes.

Scoped browser and native engineering checks passed before publication. Physical-phone performance and controller hardware compatibility are still being evaluated. See [credits](CREDITS.md) for audio and font attribution.
